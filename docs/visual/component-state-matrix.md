# BENCH visual state matrix

## Viewports

- 320×800
- 375×812
- 768×1024
- 1440×900

## Themes

- light
- dark

## Interactive states

Where applicable: default, hover, active, focus-visible, disabled, loading, error.

## Components

Core forms and actions are covered by `ProductionMatrix`. Overlay and disclosure behavior is covered by `Overlays`.

## Acceptance rule

A visual change is accepted when it is intentional, documented, and does not introduce clipping, layout shift, inaccessible focus, or token bypasses.
