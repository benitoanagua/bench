# Components

The canonical component set lives in `packages/components/src/components` and
is exported from `@bench/components`. The product-level composition examples
(`bch-alert`, `bch-data-table`, `bch-empty-state`, `bch-metric-card`,
`bch-status`, `bch-toolbar`) live in `packages/components/src/showcase` and are
exported from the same package.

- [Component matrix](./component-matrix.md) — every exported `bch-*` tag with
  semantics, keyboard, focus, loading and error coverage.
- [Component contract](./component-contract.md) — what each component must
  document.
- [API guidelines](./api-guidelines.md) — naming and event rules.
- [Showcase](../showcase.md) — the reference product surface.
